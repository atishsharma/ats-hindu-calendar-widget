Implementation notes

  • Glass = backdrop-filter: blur(38px) saturate(190%) + translucent fill + inset top highlight + masked gradient rim.
  • Electron: transparent: true; on macOS use vibrancy: 'under-window', on Windows 11 backgroundMaterial: 'acrylic' for real desktop blur (CSS blur only sees in-window content).
  • Theme: tokens on :root[data-theme]; "Auto" follows nativeTheme.shouldUseDarkColors / prefers-color-scheme.
  • Layouts map to window sizes: compact 190², standard 340×auto, wide 720×300 — resize via one setBounds, not animated intervals.
  • Traffic-light chrome appears on hover; whole widget is -webkit-app-region: drag except buttons.
  • Panchang values here are sample data.
